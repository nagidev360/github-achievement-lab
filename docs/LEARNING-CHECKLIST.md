# GitHub Learning Checklist

Track your progress as you practice professional GitHub workflows.

## Repository Foundations

- [ ] Create a repository with clear documentation
- [ ] Add a meaningful README
- [ ] Follow a consistent project structure
- [ ] Add contribution guidance

## Daily Workflow

- [ ] Create and switch branches
- [ ] Write meaningful commit messages
- [ ] Open an issue with a clear description
- [ ] Break work into a focused task
- [ ] Make a focused change
- [ ] Open a pull request
- [ ] Link the pull request to the relevant issue
- [ ] Review changes before merging

## Collaboration

- [ ] Give constructive review feedback
- [ ] Respond to review comments
- [ ] Resolve a merge conflict safely
- [ ] Use labels to organize work
- [ ] Group related work with milestones

## Before Merging

- [ ] Confirm the change solves the issue
- [ ] Check Markdown and links
- [ ] Keep the pull request focused
- [ ] Ensure documentation is updated when needed
- [ ] Review the final diff

## End-to-End Practice

Practice this complete workflow:

`Issue → Branch → Focused Change → Commit → Pull Request → Review → Merge`
